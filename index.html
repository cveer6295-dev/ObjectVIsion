THE PROJECT

01 · Ingest

Accept and validate MP4, AVI and MOV video, inspect its dimensions, frame rate and duration, then process frames one at a time.

02 · Understand

A pretrained detector identifies common objects and returns a class, bounding box and confidence score for each detection.

03 · Explain

Annotated frames, per-category counts and performance information make the model output easier to understand.

Architecture

User → Web Interface → Video / Image Input → Object Detector → Bounding Boxes + Labels → Statistics → Output.

Original technology stack

Python for application logic · Ultralytics YOLOv8 for pretrained detection · PyTorch for neural-network execution · OpenCV for video I/O and drawing · NumPy for arrays · Streamlit for the original interface.

Why YOLO?

YOLO predicts object locations and classes in a fast detection pipeline. The project uses pretrained COCO weights rather than training a new model from scratch.

What the score means

A confidence score expresses how strongly the detector supports a detection. It should not be treated as a guarantee that the prediction is correct.

Known limitations

Only common COCO classes are covered. Small, dark, blurred or occluded objects may be missed. Speed depends on hardware. Core counts are not unique-object tracking.

Future scope

Persistent object tracking · line-crossing counts · real-time webcam stream · PDF reports · richer analytics · custom-trained classes.

Responsible use: the project is a learning and demonstration system. It has not been validated for safety-critical decisions, surveillance decisions, or other high-stakes deployment.
